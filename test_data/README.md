# Test profiles

`mastered-spelling-b.spellingb-profile` is an importable learner profile generated by `scripts/generate-mastered-profile.py`. It is intentionally complete so rewards, mastered states, progress graphs, and migration behavior can be inspected without completing the entire curriculum manually.

It includes:

- all 200 stickers across 20 packs;
- all seven typing levels unlocked and mastered with Lightning Bee scores;
- all 100 High Frequency levels at 100/100;
- all 98 reviewed Sound Patterns at 100/100;
- a completed Word List day and perfect spelling-test/session history;
- the retired 160-set phonics progress record for compatibility testing.

The completed Word List uses the repository’s default lesson-plan signature. If device-wide lesson settings differ, Word Lists intentionally treats that saved day according to its normal lesson-plan migration rules. Other completion records are independent of shared settings.

Regenerate from the repository root:

```sh
python3 scripts/generate-mastered-profile.py
```

The extension build copies an explicit allowlist of runtime files into `dist/chrome-extension`; it never copies `test_data/`, `scripts/`, or this fixture.
