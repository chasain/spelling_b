# Spelling B privacy policy

Spelling B does not collect, transmit, sell, or share personal information.

Word lists, lesson settings, word-list, high-frequency, and phonics progress, typing scores, test results, and learning metrics are stored only in the user's local Chrome profile using Chrome's extension storage. This data is never sent to the developer or any third party. The extension does not contain analytics, advertising, remote code, or network requests.

Classroom setup export and import is performed entirely on the device. Exported `.spellingb` files contain word lists, lesson-plan settings, and the spelling-test limit; they do not contain student progress, results, metrics, or day counters. Spelling B can also read CSV, TSV, and XLSX word-list files locally; their contents are not uploaded or transmitted. Spelling B reads an imported file only after the user chooses or drops it, and shows a layout and content preview before applying it. The pre-import settings backup remains in local extension storage.

Spelling B uses the text-to-speech permission only to pronounce practice words through the voice selected by Chrome or the operating system. A system-provided online voice, including some ChromeOS Natural voices, may send spoken text to that system voice provider; this is controlled by the user's system voice setting and not by Spelling B. The storage permission is used only to keep word lists, settings, course progress, typing scores, and results on the device.

Removing the extension deletes its locally stored data unless Chrome retains or synchronizes it according to the user's own browser settings.

Questions about this policy can be sent to the developer contact listed in the Chrome Web Store.
