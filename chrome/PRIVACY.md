# Spelling B privacy policy

Spelling B does not transmit, sell, or share personal information. The developer does not collect it.

Word lists, optional example sentences, reviewed sound-to-spelling mappings, lesson settings, generation instructions and system prompts, word-list, high-frequency, and phonics progress, sticker awards, typing scores, test results, and learning metrics are stored only in the user's local Chrome profile using Chrome's extension storage. This data is never sent to the developer or any third party. The extension does not contain analytics, advertising, remote code, or network requests.

Classroom setup export and import is performed entirely on the device. Exported `.spellingb` files contain stable random list identifiers, word lists, optional example sentences, reviewed sound mappings, generation instructions and system prompts, lesson-plan settings, and the spelling-test limit; they do not contain student progress, sticker awards, results, metrics, or day counters. Spelling B can also read CSV, TSV, and XLSX word-list files and JSON, CSV, or TSV example-and-mapping files locally; their contents are not uploaded or transmitted. Spelling B reads an imported file only after the user chooses or drops it, and shows editable or structured content before it is saved. The pre-import settings backup remains in local extension storage. The Progress page can create a teacher CSV only after the user explicitly selects Export teacher CSV; that file is generated locally and contains the progress metrics shown in the app.

Learner profiles are also local. Profiles share device-level word lists and settings but keep each learner's progress, results, metrics, typing levels, and sticker collection separate. A user may explicitly export an active profile to a `.spellingb-profile` file and import it on another device. That file is generated and read entirely on the device and contains the learner's chosen profile name, educational progress and results, sticker collection, current selections, and a snapshot of the word lists needed to continue. Because a profile file can contain identifiable educational records, the person exporting it controls where it is copied or shared. Spelling B does not upload or receive profile files.

On supported devices, a teacher can ask Chrome's built-in on-device language model to draft short example sentences. The spelling words, teacher-provided generation instructions, built-in system instructions, and generated sentences are processed on the device by Chrome and are not sent to the developer or a third-party AI service. A teacher may explicitly copy a generated prompt and paste it into an online model; that voluntary transfer is controlled by the teacher and subject to the selected service’s privacy policy. Chrome may download and manage its local model according to Chrome's own settings and policies. Generated sentences remain editable and are stored locally only after the teacher saves Settings.

Spelling B uses the text-to-speech permission only to pronounce practice words through the voice selected by Chrome or the operating system. A system-provided online voice, including some ChromeOS Natural voices, may send spoken text to that system voice provider; this is controlled by the user's system voice setting and not by Spelling B. The storage permission is used only to keep word lists, settings, local profile names, course progress, stickers, typing scores, and results on the device.

Removing the extension deletes its locally stored data unless Chrome retains or synchronizes it according to the user's own browser settings.

Questions about this policy can be sent to the developer contact listed in the Chrome Web Store.
