# Spelling B privacy policy

Spelling B does not collect, transmit, sell, or share personal information.

Word lists, lesson settings, practice progress, test results, and learning metrics are stored only in the user's local Chrome profile using Chrome's extension storage. This data is never sent to the developer or any third party. The extension does not contain analytics, advertising, remote code, or network requests.

Spelling B uses the text-to-speech permission only to pronounce the spelling words through voices installed in Chrome or ChromeOS. It uses the storage permission only to keep the user's word lists, settings, progress, and results on their device.

Removing the extension deletes its locally stored data unless Chrome retains or synchronizes it according to the user's own browser settings.

Questions about this policy can be sent to the developer contact listed in the Chrome Web Store.
