Teacher guide

Build one classroom setup and distribute it to every learner without accounts, hosted services, or an internet connection.

1. Build

Create lists under Settings → Word Lists, or open Classroom and import CSV, TSV, or XLSX. Spreadsheet import supports lists by row, column, or title/word records.

2. Review

Check list titles and words, add useful examples, and set repetition counts under Practice Plan. Save and try one lesson before distribution.

3. Distribute

  1. Open Settings → Classroom.
  2. Name and export the .spellingb setup.
  3. Copy that file to each device.
  4. Import it and choose Replace for identical class setups.

Updating a class

Export a new package from the same teacher setup with a recognizable name and date. Stable list IDs preserve matching student progress when titles, words, examples, or reviewed sound mappings change, and every import creates a recoverable pre-import backup. Use Merge only when students should keep additional personal lists.

Shared devices and transfers

Create one local profile per learner on a shared device. Profiles share the assigned classroom setup but keep progress, metrics, typing levels, and stickers separate. A .spellingb-profile file can move one learner to another device; handle it as a private student record.

Reviewing generated mappings

Local Chrome AI can generate reference sound mappings for teacher review. The online-model Copy AI prompt creates examples only, while older or custom JSON with mappings remains importable. Core learning metrics use 98 reviewed patterns and a deterministic lookup covering 116,563 CMUdict headwords rather than generated mappings. Automatically created focus lists remain limited to the separate child-appropriate curated examples.

Reviewing progress

On a student device, open Progress for session, word-level, and sound-to-spelling patterns. Create a Sound Pattern Focus list for weak or unpracticed patterns, or select Export teacher CSV for the local session report.

Acceptance checklist

  • The same lists, reviewed mappings, and lesson plan appear on a sample student device.
  • Speech works with the device’s selected English voice.
  • A student can select the assigned list after leaving and returning to Word Lists.
  • An updated package keeps progress for matching stable list IDs.
  • The classroom package contains setup only—not student progress or results.
Teacher story: “I can prepare and verify one setup, distribute it to a class offline, and update it later without rebuilding every device by hand.”
