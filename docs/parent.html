Parent guide

Set up useful practice in a few minutes, then let the child work independently.

Set up a list

  1. Open Settings → Word Lists.
  2. Add a list, give it a clear title, and enter one word per line.
  3. Optionally add short example sentences for words that sound alike.
  4. Save, return to Word Lists, and select it.

Tune practice

Practice Plan controls beginner days, repetition counts, test size, and typing-practice length. Appearance & Voice controls keyboard guidance and speech emphasis.

Review progress

Use Progress to look for patterns over several sessions. Accuracy and word-level timing are more useful than a single fast or slow attempt.

Parent story: “I can tailor practice, understand what my child completed, and fix common setup problems without technical knowledge.”
