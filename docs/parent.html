Parent guide

Set up useful practice in a few minutes, then let the child work independently.

Set up a list

  1. Open Settings → Word Lists.
  2. Add a list, give it a clear title, and enter one word per line.
  3. Optionally generate examples and review the sound mappings.
  4. Save, return to Word Lists, and select it.

Tune practice

Practice Plan controls beginner days, repetition counts, optional Advanced missed-word review, test size, and typing-practice length. Review uses only words actually misspelled during Spell.

Review progress

Use Progress to follow 0–100 sound-to-spelling mastery, create a focused list for patterns still in progress or not yet practiced, or export a teacher CSV. A pattern reaches mastery through successful practice on ten words; mistakes do not lower the score. Children choose rewards from the separate Sticker Book page.

Profiles and moving devices

Create one local profile per learner under Settings → Profiles & Data. Word lists and lesson settings are shared on the device, while progress, metrics, typing levels, and stickers stay separate. Before changing devices, export the active learner to a .spellingb-profile file. Importing that file creates a new profile and adds only missing word lists. Treat profile files as private student records because they contain the learner name and educational history.

Parent story: “I can tailor practice, understand what my child completed, and fix common setup problems without technical knowledge.”
