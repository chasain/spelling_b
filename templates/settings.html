Spelling B uses the text-to-speech voice selected by Chrome or your operating system.

Sentence emphasis

Tune how the spelling word differs from the surrounding words. These settings stay on this device.

ChromeOS — recommended

Open Settings → Accessibility → Text-to-speech → Text-to-speech voice settings. Under the ChromeOS built-in speech engine, install and select an English voice labeled (Natural), then restart Chrome.

ChromeOS may process a Natural voice online. Spelling B does not send speech to the developer; any online voice processing is controlled by the system.

Windows

Open Settings → Time & language → Speech. Choose an English voice, or install Text-to-speech under the English language options, then restart Chrome.

Linux

Chrome uses voices provided by the installed system speech service. Install or select an English text-to-speech voice through your distribution, then restart Chrome. Names and menus vary by distribution.

How to use Spelling B

Guides for every grown-up and learner

Open the guide that matches what you want to do.

🌟Student guidePractice independently and know what comes next.

Daily routine

  1. Open Word Lists and choose the list your adult assigned.
  2. Finish each practice stage. Use the speaker whenever you need to hear a word.
  3. When the stars are full, start a new day next time.

Other practice

Use Phonics and High Frequency for focused word practice. Typing unlocks harder key groups as accuracy and speed improve.

When stuck

Slow down, listen again, and read the correction before retrying. Ask an adult if speech is silent or a word looks wrong.

🏠Parent guideSet up useful practice and understand progress.

Set up a list

  1. Open the Word Lists tab.
  2. Add a list, give it a clear title, and enter one word per line.
  3. Optionally add short examples for words that sound alike.
  4. Save, return to Word Lists, and select it.

Tune practice

Practice Plan controls beginner days, lesson repetitions, test size, and typing-practice length. Appearance & Voice controls keyboard guidance and speech.

Review progress

Use Progress to look for patterns over several sessions. Accuracy and word-level timing matter more than one unusually fast or slow attempt.

🎒Teacher guidePrepare once and distribute the same setup offline.

Build, review, and share

  1. Create lists, or use Classroom to import CSV, TSV, or XLSX.
  2. Review words, examples, and the Practice Plan, then try one lesson.
  3. Export one named .spellingb file and copy it to each device.
  4. Import it on each device and choose Replace for identical class setups.

Updating a class

Export a newly dated package. Importing preserves student progress and creates a recoverable pre-import backup. Choose Merge only when learners should retain additional personal lists.

Quick check

  • The same lists and plan appear on a sample device.
  • Speech works with the selected English voice.
  • The assigned list remains selected after navigating away and back.
  • The package contains setup only, never student results.

Optional Chrome AI

Download the language model?

Chrome needs to download and install its on-device language model before Spelling B can generate sentences. This can be a large download and may take several minutes.

Chrome system requirements
  • Windows 10 or 11, macOS 13+, Linux, or a Chromebook Plus.
  • At least 22 GB of free storage on the drive containing your Chrome profile.
  • A GPU with more than 4 GB of video memory, or at least 16 GB of RAM and 4 CPU cores.
  • Unlimited data or an unmetered internet connection for the initial model download.

The model is managed by Chrome and runs on this device. You can cancel and use Import file instead.
